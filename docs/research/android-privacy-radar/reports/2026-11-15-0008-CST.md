### 容易混淆而必须持续纠偏的旧结论
1. Android 13 运行的是移除 ARM64 `.so` 的重签名 DEX-only 衍生包，**原 APK 安装因 ABI 不匹配失败**；它不能支持 native Shell / ptrace 的实测主张。
2. 导出的 Binder、广播有静态控制面，但由 `adb shell` 调用者触发不等于普通第三方 App 在 OEM 固件里有相同权限。
3. 宿主应用信息上报集合以最近 24 小时的 UsageStats 为索引，不应自动说成“所有安装 App 都已上传”。
4. 百度 SDK 里出现 Wi-Fi / BLE / 位置扫描相关 invoke，不代表宿主每个分支都触发或每个域名都访问。
5. 宿主默认 HTTP 的 model/manuf 查询参数与 AES 加密正文应分开表述；不能误写为“明文 JSON 实际发送”。
6. 尚未找到完整“服务器指令→客户端执行”的远控闭环。模型为潜在木马审计，不是已证明恶意控制。
