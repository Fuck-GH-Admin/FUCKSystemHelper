## 本轮增量：GrapheneOS 用户级网络阻断实现（历史未归档代码，非本窗口首发）

2026-11-03，GrapheneOS 的代码仓库出现针对**整个次级用户/用户配置文件**的 `DISALLOW_NETWORK_ACCESS` 机制实现。它与此前仅讨论 `VpnService`/lockdown 的 H06 路线不同，提供了一个从 Android 权限层限制联网的具体开源工程实现，值得研究。

**精确意义与边界：**
1. 代码明确设计了基于用户限制及 `INTERNET` 权限的整用户网络隔离；不是一个仅靠 VPN 排除列表工作的“防火墙”，因此为 H06 提供了另一条实现路线。
2. 该功能的作用域是**某个 Android 用户/profile**，不是主用户里任意单个系统包；**不能推断它可直接隔离主用户内的 SystemHelper**，也不能推断 Vivo/OriginOS/HyperOS 已集成此机制。
3. Git commit 存在不等于已合并到某个稳定 ROM 或通过真机泄漏测试；本轮没有验证分支发布状态、对系统 UID / 共享 UID / native socket / 已存在连接 / DNS / IPv6 / QUIC 的完整阻断，均标 UNKNOWN。
4. 对比普通 per-app `VpnService`，这条路线可能减少 VPN 槽位冲突，但是否与 Clash 并存并做到完整阻断仍需隔离环境验证。不能宣称它是现成可部署的解决方案。
